Modifier une simulation donnée : la loi des grands nombres

Le programme ci-dessous simule un pile ou face (probabilité 0,5) répété n fois, et affiche la fréquence de « pile » obtenue. Modifier uniquement la valeur de n (10, puis 100, puis 1000, puis 10000) et observer comment la fréquence affichée se rapproche de 0,5.

Méthodologie

  1. Ouvrir le code dans PyLab avec n = 10, exécuter, puis noter la fréquence obtenue.
  2. Revenir ici, modifier n (100, puis 1000, puis 10000), et recommencer à chaque fois.
  3. Décrire ce qui se passe : la fréquence s'éloigne-t-elle ou se rapproche-t-elle de 0,5 quand n augmente ?

Compléter la fonction estimer_probabilite ci-dessous : elle doit répéter n fois un tirage à deux issues de probabilité p (avec random.random()), compter le nombre de succès, et renvoyer la fréquence observée. Compléter le code puis l'ouvrir dans PyLab pour le tester.

Mathématiques et sciences : un même langage

▼

Ce TD ne fait pas appel à une nouvelle notion mathématique : il reprend exactement le vocabulaire du TD S3 (tirage, échantillon, fréquence), mais en les manipulant sous forme de code Python plutôt que de boutons.

  • Écrire soi-même la boucle qui répète un tirage force à comprendre précisément ce que fait un échantillon de taille n.
  • Dans un métier, un programme de simulation permet de tester un très grand nombre de scénarios (production, livraisons...) sans avoir à les réaliser réellement.
  • La rigueur exigée par un programme (une indentation, un caractère oublié) rejoint la rigueur exigée par un protocole expérimental en sciences.
