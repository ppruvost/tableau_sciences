Problématique

Résoudre graphiquement f(x) = g(x) et f(x) ⩾ g(x)

Choisir le type de chaque fonction (droite ou parabole simple) et ses coefficients : les deux courbes se tracent sur le même repère et les solutions se lisent automatiquement.

Méthodologie

  1. Tracer les deux courbes représentatives de f et g sur le même repère.
  2. Les solutions de f(x) = g(x) sont les abscisses des points d'intersection.
  3. Les solutions de f(x) ⩾ g(x) sont les abscisses où la courbe de f est au-dessus (ou confondue) de celle de g.

Problématique

Étudier f(x) = a x³ + b x² + c x + d

Saisir les coefficients a, b, c, d du polynôme ainsi que l'intervalle d'étude : la dérivée, ses racines éventuelles, le tableau de variations et la courbe se construisent automatiquement.

Méthodologie

  1. Calculer la dérivée f'(x) = 3a x² + 2b x + c.
  2. Résoudre f'(x) = 0 pour trouver les éventuels points critiques.
  3. Étudier le signe de f'(x) pour dresser le tableau de variations.
  4. Utiliser le tableau de variations pour dénombrer les solutions de f(x) = c selon la position de c par rapport aux extremums locaux.
