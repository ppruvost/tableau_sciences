
Roue Classe Puzzle

 ==========================================
        ROUE CLASSE PUZZLE - README
 ==========================================

 1. Placez tous les fichiers dans le meme dossier :
    - index.html
    - espion.png
    - rapporteur.png 
    - calculateur.png
    - stratege.png
    - mediateur.png
    - expert.png

 2. Preparez votre fichier eleves.txt :
    - un prenom par ligne
    - sans virgule
     - sans separateur
    - format .txt uniquement

    Exemple :
    Emma
    Lucas
    Jade
    Noah

 3. Ouvrez index.html dans votre navigateur.

 4. Cliquez sur :
    - Choisir un fichier
     - Charger fichier
     - Tourner
     - Seance 1 ou Seance 2
 
 5. La roue attribuera automatiquement :
    - les groupes adaptatifs
     - les roles
     - les groupes puzzle
