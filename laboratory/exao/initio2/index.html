Aide à la connexion (Lubuntu / Windows)
  • Navigateur : Google Chrome, Chromium ou Microsoft Edge (version récente). Firefox ne gère pas l’USB HID depuis une page web.
  • Ouverture de la page : en double-cliquant sur index.html (adresse file://) ou, plus sûr, via python3 -m http.server 8000 dans ce dossier puis http://localhost:8000.
  • Windows : aucun pilote à installer, la console est vue comme un périphérique HID. Fermez le logiciel Initio2 s’il est ouvert (un seul programme à la fois peut lire la console).
  • Lubuntu : copiez le fichier 99-jeulin-initio.rules dans /etc/udev/rules.d/, puis sudo udevadm control --reload-rules && sudo udevadm trigger et rebranchez la console. Préférez Chrome (paquet .deb) ou Chromium non-snap : la version snap peut bloquer l’accès au port USB.
  • Utilisation : « Connecter l’appareil USB » → choisir « Initio » dans la fenêtre du navigateur → « Démarrer ».
  • Pas de mesures ? Ouvrez « Diagnostic et trames USB » : vous y voyez les octets envoyés (→) et reçus (←).
